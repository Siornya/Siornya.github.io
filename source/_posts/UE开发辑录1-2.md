## 时间系统的模型

游戏时间系统大致有以下几种结构：

1. 基于真实时间
   游戏内时间基于真实时间
   比如游戏时间直接等同于显示是时间，或者按照一定规则缩放现实时间，比如现实时间十分钟对应游戏内一小时
   这种时间系统可以用于计算离线收益
2. Tick时刻
   最经典的游戏逻辑时间，创建一种时间单位称为`Tick`游戏刻
   并且将其与实际时间联系起来，例如每秒刻数`TPS`，每刻毫秒数`MSPT`
   每次更新时计算距离上次更新经过的时间`DeltaTime`，并换算出经过的刻数$DeltaTime*TPS$
   这种时间系统具有完全确定性，保存存档和联机同步都很方便
3. 离散时间
   这种时间系统中只有时间段，没有连续流动的具体时间
   比如早晨，上午，中午，夜晚，第几回合或者第几天
   通过某些事件来使时间进入下一阶段
   这种时间系统大多用于Galgame，桌游等游戏

在本文中，我们主要讨论使用Tick驱动的游戏时间系统

## 设计与实现

时刻子系统的核心职责很简单：**把UE的帧更新（`DeltaTime`）转换为确定性的游戏刻**。它需要把累积的真实时间转换成游戏刻的数量，并且让游戏刻的增加可以被其它子系统准确计算。

对于TPS（每秒刻数），一个合理的默认值是20，即每刻50ms。这足够大多数游戏使用，Minecraft的默认值也是20。

> **关于确定性**：游戏刻的确定性来自于它基于计数而非浮点时间。两个客户端只要收到相同的输入序列，在相同的刻数上执行，结果就完全一致。

我们的C++父类选择`UTickableWorldSubsystem`，这个类继承了`UWorldSubsystem`和`FTickableGameObject`。简单来说这个类是一个生命周期属于某个`UWorld`，并且能够自动逐帧执行`Tick()`的全局系统。

那我们该怎么实现呢？首先我们需要三个核心变量每秒刻数`TPS`，累计未处理时间`AccumulatedTime`和当前刻数`CurrentTick`。然后我们至少需要override两个来自父类的函数`Tick`和`GetStatId`。

```cpp
// WorldSubsystem.h
ENGINE_API virtual void Tick(float DeltaTime) override;
virtual TStatId GetStatId() const override PURE_VIRTUAL(UTickableWorldSubsystem::GetStatId, return TStatId(););
```

- `Tick`是每帧都会执行的函数，参数`DeltaTime`是上一帧到这一帧经过的时间，单位为秒。因为FPS是不稳定的，所以每一次执行时`DeltaTime`也不一样
- `GetStatId`用于给性能统计系统提供一个标识符，它可以告诉引擎“这个 Tick 对象叫什么，把它的执行耗时统计到哪个分组中”。以后使用 Unreal Insights 或性能统计命令时，引擎可以记录这个 Tick 函数消耗了多少时间。

接下来，我们添加一个变量`bPaused`用来实现暂停功能。除此以外，还需要添加一个事件`OnSimulationTick`。在后续Tick的过程中我们可以通过广播这个事件来让其他监听这个事件的子系统做出响应。

```cpp
DECLARE_MULTICAST_DELEGATE(FOnSimulationTick); // 定义一个FOnSimulationTick事件类型
FOnSimulationTick OnSimulationTick; // 创建一个FOnSimulationTick类型的事件示例
```

### 代码

**`TickSubsystem.h`**

```cpp
#pragma once

#include "CoreMinimal.h"
#include "Subsystems/WorldSubsystem.h"
#include "TickSubsystem.generated.h"

DECLARE_MULTICAST_DELEGATE(FOnSimulationTick);

UCLASS()
class DENEB_API UTickSubsystem : public UTickableWorldSubsystem
{
	GENERATED_BODY()
	
public:

    virtual void Tick(float DeltaTime) override;

    virtual TStatId GetStatId() const override {
        RETURN_QUICK_DECLARE_CYCLE_STAT(UTickSubsystem, STATGROUP_Tickables);
    }

    virtual bool IsTickable() const override {
        return !bPaused;
    }

    UFUNCTION(BlueprintCallable)
    void SetTPS(int32 NewTPS);

    UFUNCTION(BlueprintPure)
    int32 GetTPS() const {
        return TargetTPS;
    }

    UFUNCTION(BlueprintCallable)
    void SetPaused(bool bNewPaused);

    UFUNCTION(BlueprintPure)
    bool IsPaused() const {
        return bPaused;
    }

    uint64 GetCurrentTick() const {
        return CurrentTick;
    }

    FOnSimulationTick OnSimulationTick;

private:

    int32 TargetTPS = 20;
    float TickInterval = 0.05f;
    float AccumulatedTime = 0.f;
    bool bPaused = false;
    uint64 CurrentTick = 0;
    static constexpr int32 MaxTicksPerFrame = 10;
};
```

**`TickSubsystem.cpp`**

```cpp
#include "TickSubsystem.h"

#include "Deneb/Deneb.h"

void UTickSubsystem::Tick(float DeltaTime){
	AccumulatedTime += DeltaTime;

	if (AccumulatedTime > MaxTicksPerFrame * TickInterval){
		UE_LOG(LogDeneb, Warning, TEXT("Simulation tick backlog exceeded the processing limit."));

		AccumulatedTime = MaxTicksPerFrame * TickInterval;
	}

	int32 TickCount = 0;

	while (AccumulatedTime >= TickInterval && TickCount < MaxTicksPerFrame){
		AccumulatedTime -= TickInterval;
		++CurrentTick;
		OnSimulationTick.Broadcast();
		++TickCount;
	}
}

void UTickSubsystem::SetTPS(int32 NewTPS){
	if (NewTPS<1){
		UE_LOG(LogDeneb, Warning, TEXT("TPS must be greater than 0"));
		return;
	}

	if (TargetTPS == NewTPS){
		return;
	}

	TargetTPS = NewTPS;

	TickInterval = 1.f / static_cast<float>(TargetTPS);
	AccumulatedTime = 0.f;

	UE_LOG(LogDeneb, Log, TEXT("TPS Changed: %d"), TargetTPS);
}

void UTickSubsystem::SetPaused(bool bNewPaused){
	bPaused = bNewPaused;

	UE_LOG(LogDeneb, Log, TEXT("Simulation Paused: %s"), bPaused ? TEXT("True") : TEXT("False"));
}
```

## 使用时刻子系统

### 在另一个WorldSubsystem中调用

在另一个`WorldSubsystem`中调用时推荐使用`InitializeDependency`

```cpp
#include "TickSubsystem.h"

void UMySubsystem::Initialize(FSubsystemCollectionBase& Collection)
{
	Super::Initialize(Collection);

	UTickSubsystem* TickSubsystem = Collection.InitializeDependency<UTickSubsystem>();

	if (TickSubsystem)
	{
		SimulationTickHandle = TickSubsystem->OnSimulationTick.AddUObject(
			this,
			&UMySubsystem::OnSimulationTick
		);
	}
}

void UMySubsystem::Deinitialize()
{
	if (UWorld* World = GetWorld())
	{
		if (UTickSubsystem* TickSubsystem = World->GetSubsystem<UTickSubsystem>())
		{
			if (SimulationTickHandle.IsValid())
			{
				TickSubsystem->OnSimulationTick.Remove(SimulationTickHandle);
			}
		}
	}

	SimulationTickHandle.Reset();

	Super::Deinitialize();
}

void UMySubsystem::OnSimulationTick()
{
	// 固定模拟 Tick 逻辑
}
```

## 存档支持

游戏刻计数器是存档中最关键的字段之一，所有基于时间的状态（比如建筑剩余建造刻数）都依赖它。

在你的存档结构体中添加：

```cpp
USTRUCT()
struct FGameSaveData
{
    GENERATED_BODY()

    UPROPERTY(SaveGame)
    int64 TotalTicks = 0;

    // ... 其他存档字段
};
```

存档时：

```cpp
SaveData.TotalTicks = TickSubsystem->GetCurrentTick();
```

读档时：

```cpp
TickSubsystem->LoadTicks(SaveData.TotalTicks);
```

`LoadTicks` 同时重置了 `AccumulatedTime`，避免加载后立即触发额外的游戏刻。
